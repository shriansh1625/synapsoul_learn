## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do not disclose it publicly. 

Instead, please report it to us directly by emailing **[Your Email Address Here]**. 

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If a fix is verified, we will roll out a patch and publish a security advisory.
